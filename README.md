# MutedWhisper

**MutedWhisper** — это удобный клиентский мод для Minecraft (Fabric), созданный для ролевого и скрытого общения. Он автоматически перехватывает ваши сообщения в чате и отправляет их в виде личных сообщений только тем игрокам, которые находятся поблизости.

---

## Основные возможности

* **Режим шепота:** Обычные сообщения в чате перехватываются и направляются игрокам в радиусе 100 блоков.
* **Проверка ближайших игроков (`wnear`):** Позволяет мгновенно посмотреть список всех, кто находится в зоне досягаемости вашего шепота.
* **Черный список (`bloc`):** Удобное управление списком игроков, от которых вы хотите скрыть шепот или заблокировать взаимодействие.
* **Гибкая настройка команд ЛС:** Полная совместимость с любыми серверными плагинами личных сообщений (`/msg`, `/tell`, `/w`).
* **Интерактивная справка:** Подробная система подсказок и вывода информации прямо в игре через `/wl help`.

---

## Список команд

Все команды мода используют префикс `/wl`:

* **`/wl on / off`** — включить или выключить режим шепота.
* **`/wl help`** — показать полную справку по командам.
* **`/wl wnear`** — показать список игроков в радиусе шепота.
* **`/wl cmd <msg|tell|w>`** — изменить команду для отправки личных сообщений под плагины вашего сервера.
* **`/wl bloc add <ник>`** — добавить игрока в черный список.
* **`/wl bloc remove <ник>`** — удалить игрока из черного списка.
* **`/wl bloc list`** — посмотреть текущий черный список.
